# 《万物待续》游戏类型指南

本仓库只包含该指南的公开只读静态页面（GitHub Pages 发布源）。

- 页面：开放世界生存沙盒RPG的定位、六项类别特征、类型边界、AI 内容自主权与反馈迭代原则。
- 本页说明设计目标与体验边界，**不是已上线功能清单，也不构成交付承诺**；具体可玩内容以各版本及其验证记录为准。

## 更新方式

指南正文来自项目内部方向文档，经构建为单一 `index.html` 后由维护者推送本仓库；GitHub Pages 在每次推送到 `main` 时自动重新部署。页面不会自行读取未发布的修改，请以页面底部的版本号与更新时间为准。

## 反馈

本仓库不开放 Issues，也不作为反馈通道；页面内容为只读公开文档。
