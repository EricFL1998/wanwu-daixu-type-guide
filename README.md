# 《万物待续》游戏类型指南

本仓库只包含该指南的公开只读静态页面，并作为 GitHub Pages 的发布源。

- 页面：开放世界生存沙盒RPG的定位、六项类别特征、类型边界、AI 内容自主权与反馈迭代原则。
- 本页说明设计目标与体验边界，**不是已上线功能清单，也不构成交付承诺**；具体可玩内容以各版本及其验证记录为准。

## 发布方式

Pages 从 `gh-pages` 分支根目录构建，`main` 与 `gh-pages` 始终指向同一提交；更新时两个分支一并推送，随后以公网读回核验页面内容。

指南正文来自项目内部方向文档，经构建为单一 `index.html` 后发布；页面不会自行读取未发布的修改，请以页面底部的版本号与更新时间为准。

## 反馈

本仓库不开放 Issues，也不作为反馈通道；页面内容为只读公开文档。
